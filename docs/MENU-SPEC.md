# Sound Control — 画面・メニュー仕様書

## 1. UI方針

Sound Controlは、通常のウィンドウを持たないメニューバー常駐アプリとする。

ユーザーはmacOS右上のメニューバーアイコンをクリックし、表示されたメニューから以下を操作する。

- 音量変更
- ミュートON/OFF
- 出力デバイス切り替え
- サウンド設定画面を開く

## 2. メニューバー表示

メニューバーにはアイコンのみを表示する。

アイコン方針:

- スピーカー系アイコン
- 小さく表示しても意味が伝わる
- 黒 / 白の単色でも視認できる
- MVPではSF Symbolsで代用してよい

候補:

- `speaker`
- `speaker.wave.2`
- `speaker.wave.3`

## 3. メニュー構成

メニューバーアイコンをクリックすると、以下のメニューを表示する。

```text
Sound Control
────────────────

音量：70%
[ 音量スライダー ]

□ ミュート

────────────────
出力デバイス

✓ Mac miniのスピーカー
  27E6QC
  HG585J51
  Bluetoothイヤホン
  その他接続中のデバイス

────────────────
サウンド設定を開く
起動時に自動起動 ✓
終了
```

## 4. 現在音量表示

メニュー上部に現在の音量を表示する。

表示例:

- 音量：0%
- 音量：30%
- 音量：70%
- 音量：100%
- 音量：取得できません

動作:

- アプリ起動時に現在音量を取得する
- メニューを開いたときに現在音量を更新する
- 音量変更後に現在音量を再取得する

## 5. 音量スライダー

範囲は0%〜100%。

動作:

- スライダー操作で音量を変更する
- 変更後、現在音量表示を更新する
- 現在の出力デバイスが音量変更に対応していない場合は、スライダーを無効化する

HDMI / DisplayPortなどの出力デバイスでは、macOS側で音量変更できない場合がある。その場合は、無理に変更せず、操作不可として扱う。

## 6. ミュート

表示:

```text
□ ミュート
✓ ミュート
```

動作:

- クリックでミュートON/OFFを切り替える
- ミュート状態を表示に反映する
- ミュート操作に対応していないデバイスの場合は、操作不可またはエラー表示にする

## 7. 出力デバイス一覧

音量・ミュートの下に表示する。

表示例:

```text
出力デバイス

✓ Mac miniのスピーカー
  27E6QC
  HG585J51
  Bluetoothイヤホン
```

macOSに表示されているデバイス名をそのまま使用する。

動作:

- 接続中の出力デバイスを一覧表示する
- 現在選択中の出力デバイスにチェックを付ける
- デバイスをクリックすると出力先を切り替える
- Bluetoothイヤホンなどを後から接続した場合も、一覧を更新して表示する

## 8. デバイス一覧の更新

接続デバイスが変わる可能性があるため、デバイス一覧は固定にしない。

MVPでは、メニューを開くたびに再取得する方針とする。実装が難しい場合は、「デバイス一覧を更新」を追加してよい。

## 9. サウンド設定を開く

表示名:

```text
サウンド設定を開く
```

クリックするとmacOS標準のサウンド設定画面を開く。

## 10. 起動時に自動起動

表示名:

```text
起動時に自動起動
```

表示例:

```text
起動時に自動起動 ✓
起動時に自動起動
```

動作:

- クリックでON/OFFを切り替える
- 可能であれば `SMAppService.mainApp` を使う
- MVPで難しい場合はTODOとして残してもよい

## 11. 終了

表示名:

```text
終了
```

クリックするとアプリを終了する。

## 12. エラー表示

エラー表示はシンプルでよい。

表示例:

- 音量を変更できませんでした
- この出力デバイスでは音量変更できません
- ミュートを変更できませんでした
- 出力デバイスを切り替えられませんでした
- 出力デバイス一覧を取得できませんでした
- サウンド設定を開けませんでした
- 自動起動設定に失敗しました

MVPでは、メニュー内に一時的なエラーテキスト表示する。

## 13. Dock表示

原則としてDockには表示しない。必要に応じて `Info.plist` に以下を設定する。

```xml
<key>LSUIElement</key>
<true/>
```

## 14. ウィンドウ

MVPでは通常の設定ウィンドウは作らない。将来的に必要になった場合のみ、詳細設定画面を追加する。
