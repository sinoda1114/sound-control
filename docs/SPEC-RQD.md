# Sound Control — 仕様書 / SPEC・RQD

## 1. 概要

**Sound Control** は、macOSのメニューバーから音量調整とサウンド出力デバイスの切り替えを行うための自分用Macアプリである。

macOS標準のコントロールセンターやシステム設定を開かずに、以下を素早く操作できるようにする。

- 音量の変更
- ミュートON/OFF
- 出力デバイスの切り替え
- サウンド設定画面を開く

## 2. アプリ名・PJ名

| 項目 | 内容 |
| --- | --- |
| アプリ名 | Sound Control |
| PJ名 | SoundControl |
| リポジトリ名候補 | sound-control |
| Xcodeプロジェクト名 | SoundControl |

## 3. 目的

macOS標準機能では、サウンド出力デバイスの切り替えや音量調整に以下の手間がある。

- コントロールセンターを開く必要がある
- サウンド欄を開く必要がある
- 出力デバイスの一覧が少し見にくい
- システム設定から操作すると手数が多い

Sound Controlでは、メニューバーからシンプルに操作できるようにする。

## 4. 対象ユーザー

MVPの対象は以下とする。

- 開発者本人のみ
- Mac miniを日常利用している
- 複数のサウンド出力デバイスを使う
- メニューバー常駐アプリとして使いたい
- App Store配布は初期対象外

## 5. 対象OS

MVP対象は以下とする。

- macOS
- Apple Silicon / Intel Mac の両方を想定
- まずは開発者本人のMacで動作確認できればよい

## 6. アプリ形式

必須:

- macOSネイティブアプリ
- Swift / SwiftUIで実装
- メニューバー常駐アプリ
- Dockには原則表示しない

UI方式:

- `MenuBarExtra` を使う
- メニューバーアイコンをクリックするとメニューを表示する

## 7. 操作対象

MVPでは、以下の2つに絞る。

- 音量コントロール
- サウンド出力デバイスの切り替え

対象外:

- 入力デバイスの切り替え
- マイク音量の変更
- サウンドエフェクト音量の変更
- 通知音の変更
- アプリごとの音量調整
- イコライザー
- Bluetooth接続管理そのもの

## 8. アイコン方針

- スピーカー、音量、またはサウンドを連想できるアイコン
- シンプル
- メニューバーでも視認しやすい
- 黒 / 白の単色表示でも意味が伝わる
- 初期MVPはSF Symbolsで実装してよい

## 9. 機能要件

### RQD-001：メニューバー常駐

アプリ起動中は、macOSのメニューバーにアイコンを表示する。

受け入れ条件:

- アプリ起動後、メニューバーにアイコンが表示される
- アイコンをクリックするとメニューが表示される
- Dockには基本的に表示しない

### RQD-002：現在の音量を表示

現在の出力音量を読み取り、メニュー内に表示する。

受け入れ条件:

- アプリ起動時に現在音量を取得できる
- メニューを開いたときに現在音量を表示できる
- 音量変更後、表示が更新される

### RQD-003：音量スライダー

メニュー内のスライダーで音量を変更できる。範囲は0%〜100%。

受け入れ条件:

- スライダーを動かすと音量が変わる
- 変更後、現在音量表示が更新される
- 音量変更に対応していないデバイスの場合は、操作不可またはエラー表示にする

### RQD-004：ミュートON/OFF

メニューからミュートON/OFFを切り替えられる。

受け入れ条件:

- ミュート状態を取得できる
- ミュートON/OFFを切り替えられる
- ミュート中はメニューに状態を表示する

### RQD-005：出力デバイス一覧表示

現在接続中のサウンド出力デバイスを一覧表示する。

受け入れ条件:

- 接続中の出力デバイスを一覧表示できる
- macOSに表示されているデバイス名をそのまま表示する
- 現在選択中の出力デバイスにチェックを付ける
- Bluetoothイヤホンなど後から接続されたデバイスも表示できる

### RQD-006：出力デバイス切り替え

メニューからサウンド出力デバイスを切り替えられる。

受け入れ条件:

- デバイス名をクリックすると出力先が切り替わる
- 切り替え後、現在選択中のデバイスにチェックが付く
- 切り替えに失敗した場合はエラーを表示する

### RQD-007：サウンド設定を開く

メニューからmacOS標準のサウンド設定画面を開けるようにする。

受け入れ条件:

- クリックするとmacOSのサウンド設定画面が開く

### RQD-008：Mac起動時に自動起動

Macログイン時にSound Controlを自動起動する。

MVP方針:

- 初期状態では自動起動ONでもよい
- 可能であればメニュー内でON/OFFできるようにする

受け入れ条件:

- Macログイン時にアプリが起動する
- メニューから自動起動の状態を確認できる

### RQD-009：終了

メニューからアプリを終了できる。

受け入れ条件:

- 「終了」を押すとアプリが終了する

## 10. 非機能要件

### NFR-001：軽量であること

- 常駐アプリとして邪魔にならない
- メモリ使用量を抑える
- バックグラウンドで余計な処理をしない

### NFR-002：操作が速いこと

- メニューを開いてすぐ操作できる
- 音量変更と出力切り替えを最小手数で行える

### NFR-003：安全であること

- 音量と出力デバイス以外の設定を変更しない
- 入力デバイス、通知音、サウンドエフェクト設定は変更しない
- Bluetooth接続・解除そのものは行わない

### NFR-004：接続デバイスの変化に対応すること

- Bluetoothイヤホンなど、後から接続される出力デバイスに対応する
- メニューを開いたとき、または更新処理で最新のデバイス一覧を取得する

### NFR-005：自分用として保守しやすいこと

- コードはシンプルにする
- MVPでは過度に作り込まない
- デバイス名のリネーム機能などは後続対応にする

## 11. 対象外

MVPでは以下を対象外とする。

- App Store配布
- 複数ユーザー向け配布
- 入力デバイス切り替え
- マイク音量変更
- サウンドエフェクト設定
- 通知音設定
- アプリごとの音量制御
- Bluetooth機器の接続・解除
- デバイス名の独自リネーム
- 詳細な設定画面
- 統計・ログ機能

## 12. MVP完成条件

以下を満たしたらMVP完成とする。

- メニューバーにSound Controlが表示される
- 現在の音量が表示される
- 音量スライダーで音量を変更できる
- ミュートON/OFFを切り替えられる
- 接続中の出力デバイス一覧が表示される
- 現在の出力デバイスにチェックが付く
- メニューから出力デバイスを切り替えられる
- Bluetoothイヤホンなど後から接続したデバイスも一覧に反映できる
- サウンド設定を開ける
- メニューからアプリを終了できる
- 自分のMacで問題なく動作する
